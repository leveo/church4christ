# Code of conduct

Church4Christ builds tools that serve churches, fellowships, and nonprofits. We want
everyone who uses, discusses, or contributes to the project to be treated the way you
would treat a fellow volunteer: with kindness, respect, and good faith.

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in issues, pull requests, reviews, discussions, and any
other project space, and when someone represents the project in public.

## In short

- Be welcoming to people of every background, language, denomination, and experience level.
- Disagree about code and ideas, not about people. Assume good intent and ask before assuming.
- Harassment, discrimination, personal attacks, and sharing someone's private information
  are not tolerated.
- Never post real congregation or member data in an issue or pull request; use fictional
  data, as the demo does (see [SECURITY.md](SECURITY.md)).

## Reporting

If someone's behavior concerns you, contact the maintainer privately through
[the maintainer's GitHub profile](https://github.com/leveo) rather than replying in public.
Reports are handled confidentially. Security vulnerabilities follow
[SECURITY.md](SECURITY.md) instead.

Maintainers may edit or remove comments, commits, and other contributions that break this
code of conduct, and may temporarily or permanently ban a participant, following the
enforcement guidelines of the Contributor Covenant.
