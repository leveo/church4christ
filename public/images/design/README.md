# Bundled design imagery

These same-origin decorative WebP assets ship with the application in both demo and
empty installations. They are independent of R2, setup business data and external image
services. No image-generation key or image host is needed when launching the application.

`welcome`, `community`, `family`, `children`, `worship` and `gathering` are optimized
derivatives of the existing generated seed assets. `sermon-bible`, `learning-creation`
and `kiosk-garden` were created with the built-in image generation tool in September 2026.
All images are generated illustrations or generated photographs, not pictures of actual
members, churches or events. They are decorative defaults that operators can replace.
The repository's license applies to these distributed assets.

The manifest records dimensions, bytes and origin. Keep entries synchronized when replacing
files. Uploaded media takes precedence over these defaults. Never substitute a decorative
portrait for a real member's avatar. The source seed originals and content-addressed R2 keys
remain unchanged. Every asset is below 200 KB and the complete default catalog is below 1 MB.
