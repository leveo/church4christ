# Church4Christ brand assets

The project logo, prepared from the supplied artwork (November 2026) with the white
background removed. Use these files for the project itself: the repository, docs,
social previews, and the demo site. Each church sets its own logo in admin Settings or
during `npm run onboard`.

| File | Use |
| --- | --- |
| `church4christ-logo.svg` | Full logo with wordmark, vector, transparent background |
| `church4christ-logo.png` | Full logo with wordmark, 1313×1011, transparent background |
| `church4christ-mark.png` | Icon only (church, cross, figure, arc), 512×512, transparent |
| `../../../public/favicon.svg` | Icon only, vector; the site favicon and the onboarding page mark |
| `../../../seed/media/church4christ-mark.webp` | Icon only, 512×512; the demo church's logo |
| `../social/social-preview.png` | 1280×640 GitHub social preview |

Colors: teal `#026F6C` and orange `#FA8502`, sampled from the artwork.

The SVG files are traced from the artwork rather than redrawn, so they match the PNGs.
The logos are dark teal on transparent, so place them on light backgrounds.
